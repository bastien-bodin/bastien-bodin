# Hi there, I'm Bastien! 👋 ⚛️

I am a **PhD Candidate** specializing in **Computational Physics** applied to **Planetology**. I build digital playgrounds where complex physics interact in real-time, bridging the gap between theoretical fluid dynamics and planetary evolution.

---

### 🪐 Research Spotlight: Cryovolcanism
My work focuses on modeling the rheology and dynamics of icy moons in our Solar System.

* **CryoPy:** I designed and developed this Python framework to simulate cryolava flows on **Europa** and **Titan**.
* **Methodology:** The framework extensively uses the [PySPH](https://pysph.readthedocs.io/) library for high-performance **Smoothed-Particle Hydrodynamics (SPH)**.
* **The Roots:** I built my foundation in numerical methods by developing a dedicated **Fortran prototype** from scratch before migrating to the Python ecosystem.
